========================================================
四条硬规则（踩了就变霓虹／多只）
========================================================
① 负向里一个颜色名都不要写
   （cyan / magenta / teal / purple / 红 / 蓝 都不写）
   写了反而会画出该颜色

② 正向不要给描边加厚
   写 thick / bold outline → 会变成霓虹粗线
   只用 thin lineart

③ 颜色只写在部位上
   silver-white hair / purple eyes / navy blue dress
   不要写 "purple palette" 这类整体色调词

④ 不加 full body / close-up / fills the frame / sparkles / cat companion
   → 会变特写、加减手、多出小人小动物

========================================================
不稳时的三个救命旋钮
========================================================
颜色发紫发霓虹   → QAQ 0.60 → 0.45，moria 0.75 → 0.60
角色太小         → 出图后用裁切脚本放大，不要改提示词
出现两只/多只    → (multiple girls: 2.0) 已有，再不行换种子重跑

========================================================
最稳的复刻方式（推荐）
========================================================
用你满意的那张当底图走 img2img：
  LoadImage → VAEEncode（qwen VAE，节点 3）→ 第一段采样
  denoise 0.50 ~ 0.55
  正向只写表情 + 姿势，颜色让底图带
  SaveImage 接 VAEDecode（节点 8）
这样能锁住画风，只换表情。
