【白 · 穿搭思路（按场景）】

先说清她衣柜里实际有什么（不要凭空给她加衣服）：
连衣裙：藏青 V 领（米白蕾丝、腰间浅蓝缎带，最常穿）、白色夏日吊带裙、白色针织裙
上装：白色泡泡袖衬衫、米白粗针开衫、白色运动外套（橙条袖）、藏青水手领上衣、浅蓝薄衬衫、白色连帽卫衣
下装：藏青百褶短裙、灰色运动短裤、白色宽松运动裤、深蓝百褶裙
外套：藏青短款魔女披肩、米色薄风衣
鞋：深棕乐福鞋、白帆布鞋、白运动鞋、白细带凉鞋
其他：白猫耳（本体，不算配饰）、魔物素材小包、符纸袋

========================================================
一、居家日常（最常出现）
========================================================
1. 白色连帽卫衣 + 灰色运动短裤 + 白运动鞋（袜子不穿也行）
   → 早上刚起、头发乱、抱着杯子；适合"赖床未遂"的画面
2. 白色泡泡袖衬衫 + 白色宽松运动裤 + 赤脚
   → 洗完澡、头发半干、坐在沙发上擦头发
3. 米白粗针开衫 + 藏青百褶短裙 + 白帆布鞋
   → 在家也穿得整齐一点，等他回来

========================================================
二、出门买菜 / 便利店（轻便）
========================================================
4. 浅蓝薄衬衫 + 白色运动裤 + 白帆布鞋 + 帆布袋
   → 素颜、头发随便扎一下；塑料袋里露出葱
5. 藏青水手领上衣 + 深蓝百褶裙 + 深棕乐福鞋
   → 想稍微好看一点，但仍方便

========================================================
三、去职业者协会 / 魔法杂货铺（带点职业感）
========================================================
6. 藏青 V 领连衣裙 + 藏青短款魔女披肩 + 深棕乐福鞋 + 符纸袋
   → 披肩是重点：一看就是魔法师；包里有净化符和清单
7. 白色泡泡袖衬衫 + 藏青百褶短裙 + 魔女披肩 + 乐福鞋
   → 更像"登记在册的魔法师"，去办证件或接委托

========================================================
四、公园 / 河边 / 晒太阳（她喜欢的）
========================================================
8. 白色夏日吊带裙 + 白细带凉鞋 + 薄开衫搭在臂弯
   → 河边长椅、草莓盒、头发被风吹乱
9. 白色针织裙 + 白帆布鞋 + 米色薄风衣
   → 阴天或傍晚，风大一点时

========================================================
五、下雨天
========================================================
10. 白色连帽卫衣 + 深蓝百褶裙 + 白运动鞋 + 伞（经常忘带）
    → 狼狈但可爱；头发上的水珠
11. 米白开衫 + 白运动裤 + 乐福鞋 + 便利店买的塑料伞
    → 临时躲雨、鞋尖湿了

========================================================
六、和他出门 / 约会
========================================================
12. 藏青 V 领连衣裙 + 浅蓝缎带 + 乐福鞋 + 只戴一只耳饰
    → 认真打扮过，但会不自然地拽裙摆
13. 白色针织裙 + 米色薄风衣 + 白细带凉鞋
    → 天气好、走远一点、可能去海边
14. 白色泡泡袖衬衫 + 深蓝百褶裙 + 魔女披肩
    → "职业者 + 女朋友"的混合感，去协会附近的店吃饭

========================================================
七、练魔法 / 做道具（会弄脏）
========================================================
15. 旧白衬衫（衣柜里最不打紧那件）+ 运动短裤 + 赤脚
    → 袖子卷到手肘，桌上摆着冒烟的药水
16. 米白开衫（袖口被烧了个洞）+ 运动裤
    → 失败过很多次的证据就在衣服上

========================================================
八、冬天 / 怕冷
========================================================
17. 白色连帽卫衣 + 白运动裤 + 厚袜 + 米色薄风衣
    → 裹着毯子、手脚凉、要人焐
18. 藏青 V 领连衣裙 + 白色针织裙外搭 + 开衫 + 乐福鞋
    → 叠穿， visibly 怕冷

========================================================
九、睡衣 / 睡前
========================================================
19. 宽松白 T + 灰色运动短裤（当睡衣穿）
20. 他的旧卫衣（她拿来当睡衣）+ 光脚
    → 领口太大、袖子太长，这是"同居"最直观的证据

========================================================
配色建议
========================================================
· 主色只有三个：白、藏青、米白
· 点缀色：浅蓝（缎带、袖口）、橙（运动外套的条）、深棕（鞋）
· 不要给她加粉色、黑色大面积的单品（魅魔状态除外）
· 全身超过三种颜色就删一件

========================================================
几条穿搭逻辑（写的时候别违背）
========================================================
1. 她怕冷：室内也可能穿开衫或卫衣；出门一定带外套
2. 她笨手笨脚：白衣服上出现小污渍很正常
3. 她缺钱但不邋遢：衣服旧但干净、熨得平
4. 大魔导师之后：衣服没大变，只是披肩更常穿、包里多了高级材料
5. 魅魔化只在小白面前：那种露出度高的状态不会出现在别人面前
